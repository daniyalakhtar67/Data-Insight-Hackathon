# Data Insight Hackathon 2026 – ColdChain Watch

## About the Project

**ColdChain Watch** is a data-driven project developed during **Hack Insight 2026 (TECH FEST '26)**.

The project focuses on monitoring external weather conditions and heat exposure for cold-storage operators in Pakistan.

By collecting historical weather information from reliable data sources, the system helps users understand environmental heat exposure patterns and make more informed operational decisions.

Our team worked collaboratively to develop a data pipeline, process weather information, and build a dashboard for presenting meaningful insights.

## Problem Statement

Cold-storage facilities need to consider external environmental conditions when managing temperature-sensitive goods. However, historical weather information can be difficult to collect, organize, and analyze.

The challenge is to transform reliable weather data into useful and accessible insights that support better operational awareness.

## Our Solution

ColdChain Watch provides a data-driven approach to monitoring external heat exposure conditions.

The project uses weather datasets from independent sources, processes the collected information through structured data layers, and presents insights through a dashboard.

Our approach emphasizes data reliability, traceability, reproducibility, and responsible use of AI.

## Key Features

- **Weather Data Collection:** Collects historical weather information from external data sources.
- **Data Processing:** Organizes raw weather data into structured processing layers.
- **Data Quality:** Maintains data validation and source traceability.
- **Heat Exposure Monitoring:** Helps analyze external environmental heat conditions.
- **Interactive Dashboard:** Presents processed information in an accessible format.
- **AI Integration:** Includes AI-oriented components for exploring and explaining data insights.

## Data Sources

The project uses the following weather data sources:

- **Open-Meteo Historical Weather API** – Historical weather information.
- **NASA POWER API** – Hourly meteorological data.

Data collection emphasizes source documentation, licensing information, and file integrity.

## Technologies & Tools

- **Python** – Data processing and backend development.
- **Streamlit** – Interactive dashboard development.
- **Open-Meteo API** – Historical weather data.
- **NASA POWER API** – Meteorological data.
- **Git & GitHub** – Version control and team collaboration.

## Project Components

The project is organized into different components:

- `dashboard/` – Dashboard interface.
- `genai/` – Generative AI components.
- `model/` – Model-related components.
- `pipeline/` – Data collection and processing.
- `rag/` – Retrieval-Augmented Generation components.
